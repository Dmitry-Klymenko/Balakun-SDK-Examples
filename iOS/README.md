# Balakun iOS Examples

This repository contains usage examples for `BalakunMobileSDK`.

## Included

- `BalakunSampleAppiOS` - SwiftUI sample app (iOS, iPadOS, macOS)

The sample app resolves SDK via SPM from GitHub branch `main`:

- `https://github.com/Dmitry-Klymenko/Balakun-SDK.git` (`main`)
